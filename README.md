# Laundry Bag — Landing page

صفحة هبوط Laundry Bag: غسيل وكي واستلام وتسليم من باب البيت — التجمع، الرحاب، مدينتي.

موقع ثابت بالكامل: HTML و CSS و JavaScript عادي. مفيش build ولا باك-إند.

## المحتوى

| الملف | الغرض |
|---|---|
| `index.html` | الصفحة الرئيسية — هيرو، رحلة الطلب، الأسعار، الباقات، قبل/بعد، التطبيق، تواصل |
| `terms.html` | الشروط والأحكام |
| `privacy.html` | سياسة الخصوصية |
| `refund.html` | الاسترداد والإلغاء |
| `shipping.html` | التوصيل والتسليم |
| `assets/prices.json` | الأسعار المعروضة في جدول الأسعار |
| `assets/plans.json` | الباقات الشهرية |

صفحات السياسات الأربعة مطلوبة لمراجعة مزوّد الدفع، فلازم تفضل على عناوين حقيقية قابلة للفتح.

## التشغيل محليًا

```
python -m http.server 4321
```

وبعدين افتح <http://127.0.0.1:4321>.

## النشر

أي استضافة ملفات ثابتة تنفع — Cloudflare Pages أو Netlify أو GitHub Pages. مفيش أمر build: ارفع مجلد المشروع زي ما هو.

## الأصول

الصور كلها WebP ما عدا أيقونة التطبيق. المجلد كله أقل من ٦٠٠ كيلوبايت، فخليه كده: أي صورة جديدة تتحوّل WebP وتتظبط على المقاس اللي هتتعرض بيه فعلاً قبل ما تتضاف.
